Projet académique de développement d'une application de bureau pour la **gestion des prêts bancaires**.

# Objectif
Développement d'un système complet permettant à une banque de gérer efficacement ses opérations de prêt : enregistrement des demandes, suivi des clients, gestion des échéances et remboursements.

# Technologies utilisées
- **C#** (.NET Framework / .NET 6+)
- **WPF** (Windows Presentation Foundation) pour l'interface graphique moderne et interactive
- **MySQL** comme base de données relationnelle

# Fonctionnalités principales
- **Opérations CRUD** complètes (Create, Read, Update, Delete)
- Gestion des Clients
- Gestion des Prêts (montant, taux, durée, date d'octroi, statut...)
- Suivi des remboursements et échéances
- Recherche et filtrage avancé
- Interface utilisateur intuitive avec WPF (MVVM)
- Connexion sécurisée à la base de données MySQL

# Contexte
Projet réalisé dans le cadre d'études en développement d'applications de gestion (Gestion Informatique / Génie Logiciel).
